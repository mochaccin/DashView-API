# dashview-back

A CSGO professional teams and players performance tracker, made for analysis by coaches, built on Spring Boot and Svelte.

## Tags

- Spring Boot
- backend
- Svelte
- web-development
- MongoDB
- chart.js

## Problem

Lack of a platform that facilitates the visualization of performance of a team or players based on their past matches and the current season through graphs and charts.

## Solution

A dashboard style platform that displays all sorts of performance stats for players and teams, from kd/a, headshot %, % of clutches, etc.

## How it works

It's a simple dashboard for coaches, making it easy to see the performance of other teams and players. Website made with Svelte which communicates with a Spring Boot REST API and a MongoDB database that serves the information to the website.

## Comments

> It was such a good learning experience, not only I got to try out Svelte, I also learned to integrate different type of graphs and customize their CSS to fit the aesthetic of the website.
